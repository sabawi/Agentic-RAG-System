TECHNICAL SPECIFICATIONS - DOCUMENT INTERROGATION SYSTEM

System Architecture:
- FAISS vector database for similarity search
- SQLite for metadata storage  
- Ollama integration for embeddings
- 2-stage LLM pipeline integration

Performance Metrics:
- Embedding dimension: 768 (nomic-embed-text)
- Chunk size: 1000 characters
- Chunk overlap: 200 characters
- Search results: Top-K similarity matching
- Processing speed: ~100 documents per minute

Supported File Formats:
- Text files: .txt, .md
- Documents: .pdf, .docx
- Spreadsheets: .xlsx
- Web content: .html
- Images: .jpg, .png, .bmp, .tiff (with OCR)

API Endpoints:
- POST /documents/index-directory
- POST /documents/search  
- POST /documents/interrogate
- POST /documents/watch-directory
- GET /documents/stats

Security Features:
- Local processing only
- No external API dependencies
- Encrypted vector storage
- Access control via existing FastAPI middleware

Scalability:
- Handles up to 10,000 documents efficiently
- Memory usage: ~50MB per 1,000 documents
- Disk space: ~1MB per 100 document chunks
- Concurrent search: Up to 50 simultaneous queries
